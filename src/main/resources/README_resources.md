Resource files for GearForge (advanced models + GUI assets)

What's included:
- Blockstates with facing variants so blocks face the player when placed.
- Block models with separate face textures (front/back/side/top/bottom).
- Item models that use block models for item form.
- GUI textures: a background and a card-style template (card_front_template.png and card_back.png).
- Language strings for GUI labels.

Textures:
- The PNG files included below are base64-encoded placeholders (1×1 transparent). They decode into valid PNGs so Minecraft will not complain.
- To replace them with full 16×16 or 32×32 pixel art: create images and overwrite the files under assets/gearforge/textures/.
